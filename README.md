# 🛍️ GretKart - Django E-Commerce Website

GretKart is a Django-based e-commerce web application developed to provide users with a simple and convenient online shopping experience.

Users can browse products, explore categories, add products to their shopping cart, manage their wishlist, and place orders.

## 🚀 Features

- User Registration and Login
- Product Categories
- Product Listing
- Product Details
- Shopping Cart
- Add and Remove Wishlist Items
- Checkout System
- Order Management
- Responsive User Interface
- Django Admin Panel

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript
- Bootstrap
- jQuery

### Backend
- Python
- Django

### Database
- SQLite
